3. Options

What happens during import
  1. Automatic format detection (OpenAPI 2.0, OpenAPI 3.x, proto).
  2. Parsing and validation: errors stop the import; warnings are shown afterwards.
  3. The original file is preserved and available for download.
  4. Metadata, endpoints and models are extracted.
  5. A new revision is created; previous revisions remain available for browsing and comparison.
